# Algoritma

## Bilangan ganjil atau genap

Membuat algoritma menentukan bilangan ganjil atau genap

1. Mulai
2. Siapkan bilangan
3. Bagi bilangan tersebut dengan bilangan 2 yang hasil nya 0 maka di sebut bilangan genap
4. Kalau tidak menghasil kan nilai 0 maka di sebut bilangan ganjil
5. Selesai
